# README screenshots

These images are direct captures of the locally served production app, with the current T-Zero identity. Mission schedules, counts, and countdowns are a point-in-time view, not current launch announcements.

- `overview.png`: mission-control overview, source-connected launch data, and Earth.
- `fleet-explorer.png`: Saturn V in the NASA heritage viewer.
- `mission-history.png`: curated exploration milestones.

The model close-ups referenced by the README live in `public/models/` and show the repaired asset materials.
